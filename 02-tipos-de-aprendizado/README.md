# 02. Tipos de aprendizado

Os arquivos da aula «Tipos de aprendizado» do curso ML: preparação e validação.

| Arquivo | Para quê |
|---|---|
| `onde_esta_a_resposta.py` | A conta da seção 3: quantas linhas dos pedidos e das admissões já têm a resposta preenchida |
| `minha-classificacao.md` | A folha do exercício: seis pedidos da Loja Exemplo para classificar |

O `onde_esta_a_resposta.py` lê as duas bases compartilhadas do kit, em `../dados/loja/pedidos.csv` e `../dados/pessoas/admissoes.csv`. Rode de dentro dessa pasta:

```bash
python3 onde_esta_a_resposta.py
```

A saída tem quatro linhas. A primeira é `pedidos: 2400 linhas; resposta (cancelado) preenchida em 2400, vazia em 0`.

Ele usa o pandas, que o README do kit já instala. Não precisa de internet.

O exercício não tem código. Você responde na folha.

No Windows, troque `python3` por `py`.
